# Docs

Project documentation. Keeping these current is part of "done" — see `/CLAUDE.md` rule 5.

## Contents

- **[adr/](adr/)** — Architecture Decision Records: every non-trivial design choice and why.
- **[`/worklog-prd (1).md`](../worklog-prd%20(1).md)** — the product spec (source of truth for *what*).
- **[`/tasks/`](../tasks/)** — the live work queue and completed-work log.

## Where things go

| You wrote… | Put it in… |
|------------|-----------|
| Why a design choice was made | a new ADR in `docs/adr/` |
| What to build / requirements | the PRD (or a new doc here, linked from this index) |
| What you're working on now | a task in `tasks/todo/` |
| How to run / set up something | a doc here, linked from this index |

When you add a doc, link it from this index.
